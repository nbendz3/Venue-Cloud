=== REPLICATION ADDENDUM — PASS 5: DEEP DIVE ON HIERARCHY, BEO BUILDER, AND REPORTS ===

This pass documents the precise mechanics of the three-level hierarchy, the complete BEO/menu building workflow, and the full custom report builder workflow.

## 1. THREE-LEVEL HIERARCHY: MASTER EVENT → EVENT → FUNCTION

### Conceptual Relationships
- One MASTER EVENT can contain many EVENTS (across multiple sites/dates)
- One EVENT contains many FUNCTIONS (sessions/meals happening within that event)
- One FUNCTION contains many SERVICE MENUS (BEOs)
- One SERVICE MENU contains many SERVICE TYPES
- One SERVICE TYPE contains many SERVICE ITEMS

### Visual Hierarchy Indicators
- Master Event pages: PURPLE header bar/accent color
- Event pages: RED header bar/accent color
- Function pages: ORANGE header bar/accent color
- Breadcrumbs always show the full chain: "Event: [Name] | Master: [Name]"

### Navigation Between Layers
Every Function detail and Function Services page shows a FUNCTION PICKER DROPDOWN at the top:
  "Show Details for Function: [Function#] - [Function Name] on [Day Date] at [Time]-[Time] in [Location]"
This allows switching between functions within the same event without going back.

## 5. FUNCTION SERVICES / BEO BUILDER — /events/eventServicesDetails/:functionId

Page title: "Function Services — [FunctionName]: [EventName] - [Date] - [FunctionNumber] - [Location]"
Breadcrumbs: Event | Master Event

Sub-header: **Show Details for Function** dropdown (same function picker as Function detail)

### Page-Level Toolbar
- **[Add Menu]** — opens Add Menu dialog (choose from template library or create blank)
- **[… More Actions]** dropdown:
  - Reorder Menus
  - Copy Services (copy all menus from another function)
  - View Financial Details
  - View Function Details
  - **View Daily Menu Mix** (special view: shows all items across all menus in a single flat list)

### Menu Section Structure (one per menu on the function)
Each menu is a colored card (orange header = event color):

**Menu Header Display Fields:**
- Function Menu Name
- Pricing Type
- Menu Quantity (auto-calculated: Number Required × Per Number of Guests × Function Attendance)
- Menu Total Charges ($)
- Menu Total Cost ($)

**Menu Header Buttons:**
- [Edit Menu] — opens the Function Menu edit form (see below)
- [… More Actions]:
  - Add New Menu (adds another blank menu to this function)
  - Delete Menu
  - **Add Service Types** (adds a service type section to this menu)
  - Reorder Service Types / Items

### Service Type Section Structure (one per service type in the menu)
Each service type is a sub-section within a menu, indicated by a blue accent line and the service type name:

**Service Type Header:**
- Service type name (e.g., "Buffet", "Food & Bev", "Setup and Service")
- Collapse/expand toggle (^ / v arrow)

**Service Type Sub-toolbar:**
- [Add Custom Items] — opens item selector
- [… More Actions]:
  - Delete Service Type
  - **Add Items from Menu** (pick from this function's other menus)
  - **Add Items from Master List** (pick from the global service item library)
  - **View/Add Related Service Items** (add related/complementary items)
  - Reorder Service Types / Items

**Service Type Summary:**
- Service Type Total Charges: $X.XX
- Service Type Total Cost: $X.XX
- Maximum # Selections: (Unlimited or specific number)

**[Delete Selected Items]** button (bulk delete)

### Service Item Table (within each service type)
Default view columns:
[checkbox] | Actions (Edit Menu | Delete) | [dietary icon] | Item | Notes | Notes Internal | Quantity | A La Carte Price | Add-On Price | # Hours | Total | Revenue Center | Applied Rates | Category | Category Sub Option | Category II

### "New Service Type" placeholder
When a new service type is added but not yet configured, it appears as a collapsed row with a ∨ arrow labeled "New Service Type" and a "Service Type Fields" expandable section.

**Section: Add/Edit Sorts**

**Section: Add/Edit Calculations**
- Report Column (dropdown — typically only numeric fields)
- Calculations: [Average] [Sum] [Maximum] [Minimum] checkboxes (can select multiple)
- [Add] button → appends to Applied Calculations table
- Applied Calculations table: Column | Average | Sum | Maximum | Minimum

Calculations appear as footer rows at the bottom of the report (or per group if grouped).

---

**Section: Add/Edit Filters**
- [Add Filter Group] button — creates a new filter group

**Filter Group structure (one or more):**
Header: "Filter Group N"
- [Add Filter] — adds a filter row
- [Add Filter Group] — adds another group (groups are AND-ed together)
- [Delete Filter Group] — removes this group

**Filter row structure (one or more per group, rows within group are AND-ed by default):**
- Row N:
  - Filter Operator (dropdown: blank for row 1, "AND" or "OR" for subsequent rows)
  - Report Column (dropdown: all available columns including non-selected ones)
  - Comparator (dropdown: changes based on column type):
    - Text: contains, does not contain, equals, does not equal, starts with, is blank, is not blank
    - Number/Currency: equals, does not equal, less than, greater than, less than or equal, greater than or equal, is blank, is not blank
    - Date: on, before, after, between, in last N days, is blank, is not blank
    - Dropdown/list: equals, does not equal, is in list, is not in list
  - Value (input field — type depends on column: text input, number, date picker, multi-select, or dropdown)
  - [Delete] button

Logic: Rows within a group follow their Filter Operator (AND/OR). Groups themselves are AND-ed together.

- **Save** — saves to current name/folder
- **Save As** — prompts for new name/folder (creates a copy)
