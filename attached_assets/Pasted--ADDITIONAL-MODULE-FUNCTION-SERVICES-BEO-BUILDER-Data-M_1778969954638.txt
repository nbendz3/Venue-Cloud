id, name, menu_number, category (Wedding Menus / Banquet Menus / Beverage Menus / Setup and Service Menus / Amenities), pricing_type (A La Carte Pricing / Package Pricing - Percentage Amount Allocation / Package Pricing - Monetary Amount Allocation), package_price, package_cost, use_inclusive_pricing, created_by, created_at

id, function_id, template_id (nullable — null if custom), function_menu_name, pricing_type, auto_calculate_quantity (bool), number_required, per_number_of_guests, menu_quantity (calculated), menu_total_charges (calculated), menu_total_cost (calculated), use_function_time_range (bool), start_time, end_time, menu_location, description, menu_notes, notes_internal (bool), created_at, updated_at

#### service_types (groupings within a menu)
id, function_menu_id, service_type_name (Buffet / Food & Bev / Set Up / Tasting Setup / Enhancements / Audio Visual Equipment / Labor / Miscellaneous), use_function_time_range (bool), start_time, end_time, service_location, description, service_notes, notes_internal (bool), max_selections (null = unlimited, or number), display_order, service_type_total_charges (calculated), service_type_total_cost (calculated)

#### service_items (individual line items within a service type)
id, service_type_id, item_name, description, notes, notes_internal (bool), quantity, auto_quantity (bool), a_la_carte_price, add_on_price, cost, use_ingredients_cost (bool), number_required, per_number_of_guests, quantity_precision (Whole / Half / Quarter), category (dropdown), category_sub_option, category_ii, mark_item_internal (bool), mark_quantity_internal (bool), use_function_time_range (bool), start_time, end_time, charge_hourly (bool), auto_hours, num_hours, use_function_setup_teardown (bool), setup_minutes, teardown_minutes, apply_overtime (bool), overtime_hours_price, overtime_hours, hours_precision (Quarter / Half), revenue_center (Food / Alcoholic Beverage / Non-Alcoholic Beverage / Rentals / Equipment / Labor / Service Fees / Room Rental / Cover Charge / Outside Services / Other Taxable / Other No Taxes), applied_rates (Gratuity and Sales Tax / Sales Tax Only / Gratuity Only / None), total (calculated), display_order

#### revenue_centers
id, name, sales_tax_rate (%), occupancy_tax_rate (%)
Seed with: Food 7.75%/0%, Alcoholic Beverage 7.75%/0%, Non-Alcoholic Beverage 7.75%/0%, Service Fees 0%/0%, Guest Rooms 0%/11.5%, Room Rental 7.75%/0%, Labor 0%/0%, Equipment 7.75%/0%, Rentals 7.75%/0%, Other Taxable 7.75%/0%, Other No Taxes 0%/0%, Cover Charge 0%/0%, Outside Services 0%/0%

id, name (Gratuity 22% / Gratuity 20% / Gratuity 18%), rate_percent, is_taxable, use_rev_ctr_rates, use_fee_tax_rates, sales_tax_rate, occupancy_tax_rate

#### payments
id, related_type (Event / Function), related_id, date, payment_amount, allocated_amount, payment_method (Check / Credit Card / Cash / ACH / Wire), payment_type (Deposit / Payment), description, salesperson, credit_card_id (nullable), from_gateway (bool), posted (bool), is_event_payment (bool)

#### adjustments
id, function_id, date, amount, revenue_center_id, applied_rates, description, salesperson

#### additional_fees
id, function_id, date, amount, service_fee_id, description, revenue_center_id, salesperson

#### deposits_scheduled
id, related_type (Event / Function), related_id, date, amount, description, salesperson, has_task (bool)

#### function_lifecycle_history
id, function_id, event_status (New / Inquiry / Proposal / Tentative / Definite / Event Order / Guaranteed / Actualized / Thank You / Closed), date, salesperson, forecasted_charges, charges, adjusted_charges, cost, margin, margin_percent

### BUSINESS LOGIC TO IMPLEMENT

1. **Auto-calculate Menu Quantity:** When Auto Calculate Quantity is checked, Menu Quantity = ceiling(Number Required × Function Estimated Attendance / Per Number of Guests)

2. **Item Total calculation:** Total = (A La Carte Price × Quantity) + (Add-On Price × Quantity if applicable)

3. **Service Fee calculation:** Applied Rates drives which fees are added — "Gratuity and Sales Tax" adds both, "Sales Tax Only" adds sales tax, "Gratuity Only" adds gratuity, "None" adds nothing

4. **Tax calculation per revenue center:** Each revenue_center has its own sales_tax_rate and occupancy_tax_rate applied to adjusted charges

5. **Function lifecycle:** When a function is created, automatically create a "New" lifecycle history entry. Advancing status creates a new history entry with a snapshot of current financial figures

6. **"Post Function"** action: locks the financial figures and creates a "Most Recent" lifecycle history snapshot

7. **Menu template library:** Templates are site-wide master menus. When applied to a function, they are copied (not linked) so edits don't affect the template

8. **Balance Due:** = Total Charges − Payments Received (can be negative if overpaid)

9. **Margin %:** = (Adjusted Charges − Cost) / Adjusted Charges × 100 (handle division by zero)
