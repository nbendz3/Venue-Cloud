### REPORT BUILDER MODULE — Full Specification

**URL:** /reports/new (type selection), /reports/:id/edit (builder), /reports/:id/run (results)

**New Report — Type Selection Page:**
- Grid of all report types with Name + Description columns
- Radio/checkbox select one type → "Create Report" button
- 90+ types — implement at minimum: Event, Function, Event Lead, Contact, Account, Task, Function Menu, Function Service Item, Guest Rooms Block, Function Financial Snapshot, Function Revenue Center Financials

**Report Edit Page — Sections:**

1. **Report Properties**
   - Name (text input, required)
   - Description (textarea)
   - Folder (tree picker matching the folder hierarchy)
   - Owner (lookup)
   - Report Type (read-only, set at creation)
   - Last Updated metadata (read-only)

2. **Report Options**
   - Date Type (dropdown): options vary by report type — e.g., "Event - Day/Date", "Function Date", "Created Date", "Last Updated Date"
   - Date Range (dropdown): Today, Yesterday, This Week, Last Week, This Month, Last Month, This Quarter, Last Quarter, This Year, Last Year, Next 7 Days, Next 14 Days, Next 30 Days, Next 60 Days, Next 90 Days, Next 180 Days, Custom
   - Start Date (date picker, shown when Custom selected)
   - End Date (date picker, shown when Custom selected)
   - Hide Detail Rows (checkbox — collapses to grouped summary rows)

3. **Select Columns (dual-list builder)**
   - Left panel: "Available Columns" — grouped by category (Function, Event, Financial, Primary Contact, etc.), each group expandable to show individual fields
   - Search box to filter available columns
   - Click a field name to add it to Selected Columns
   - Right panel: "Selected Columns" — ordered list with Delete button per item, draggable to reorder

4. **Add/Edit Groupings**
   - Report Column dropdown (all selected columns)
   - Sort Order dropdown (Ascending/Descending)
   - Add button → adds row to "Selected Groupings" table (Column | Sort Direction | Delete)

5. **Add/Edit Sorts** (same UI pattern as Groupings)

6. **Add/Edit Calculations**
   - Report Column dropdown
   - Calculation checkboxes: Average, Sum, Maximum, Minimum (multi-select)
   - Add button → adds row to "Applied Calculations" table (Column | Average | Sum | Maximum | Minimum | Delete)

7. **Add/Edit Filters**
   - "Add Filter Group" button creates a group
   - Each group: "Filter Group N" header + "Add Filter", "Add Filter Group", "Delete Filter Group" buttons
   - Each filter row: Filter Operator (AND/OR, shown after first row), Report Column dropdown (all available columns for report type), Comparator dropdown (Equals, Not Equals, Contains, Does Not Contain, Starts With, Is Empty, Is Not Empty, Greater Than, Less Than, Greater Than or Equal, Less Than or Equal, Between), Value input (text/date/number depending on column type), Delete button
   - Multiple filter groups are AND-ed together; rows within a group use the row's operator

**Action buttons:** Preview Report (runs and shows inline), Download Printable View, Export (CSV/Excel), Save, Save As (prompts for new name/folder), View Charts, Delete, Done (returns to list)

**Report Results Page:**
- Paginated data table matching selected columns
- Column headers clickable for sort
- Grouping headers collapse/expand rows
- Calculation totals row at bottom
- Export button

**Scheduled Report Jobs:**
- Create schedule: Report, Frequency (Daily/Weekly/Monthly), Day/Time, Output Format (PDF/Excel/CSV), Recipients (email list)
- View active scheduled jobs table
- View Report Job Results — history table with Download Results link

### EVENT MORE ACTIONS (…) MENU — Full Options

On the Event Detail page, the `…` button opens:
- **New Event** (→ new event form)
- **Copy Event** (copies all event fields, prompts for new date)
- **Multi Copy Event** (copies event multiple times, prompts for number of copies and date range/pattern)
- **Move Event** (changes event date)
- **Change Master Event** (reassigns event to different master event)

On the Function Detail page, the `…` button opens:
- **New Function**
- **Copy Function** (copies to same or different event/date)
- **Save and Copy Function** (during edit)

On the Function Services page, each Menu's `…` opens:
- **Copy Menu to Another Function**
- **Delete Menu**

Each Service Type's `…` opens:
- **Add Items from Library** (browse master service items)
- **Copy Service Type**

- Each lifecycle status (New/Tentative/Definite/Closed/etc.) gets a configurable color
- The calendar block also shows a triangle/arrow indicator icon (▲) for events with guest rooms blocks

Implement this as a legend panel that toggles visibility, showing colored swatches for each status.
